# AstrBot 预售补款提醒与小店情报管家 (`astrbot_plugin_preorder_reminder`)

专为手办、模玩、周边爱好者打造的预售订单与小店补款追踪插件。彻底解决预定太多容易遗忘、淘宝小店不发短信、补款群被闲聊刷屏容易漏看的痛点。

---

## 核心特性

1. **三维立体情报监控**：
   * **QQ 补款群静默嗅探（零打扰）**：监听小店自建的 QQ 预售/补款群。自动过滤群友闲聊，只提取店主/管理员发布的补款与开订通知；**Bot 在群内绝对静默（不发一言、不闲聊、不响应普通指令）**，命中时私聊推送订阅用户。
   * **微博动态监控**：支持微博 PC Ajax 与移动端接口，支持用户配置微博 Cookie（通过 `/设置微博cookie` 或面板）或接入自建 RSSHub，轻松突破微博山海防火墙 432 反爬限制。
   * **微信公众号监控**：支持接入 WeWe-RSS / 微信读书源，自动拉取并解析小店发布的《XX月补款清单汇总》推文。
2. **小店档案库与内置预设**：
   * 自动开箱即用预设热门官方店铺：**良笑GoodSmile**（UID: `2638252657`，别名: GSC/良笑/GoodSmile）、**GoodSmile良笑社**（UID: `1798143541`）、**猫受屋**（UID: `1874987014`）。
   * 支持通过自然语言或指令创建小店档案，为每个小店绑定其补款群、公众号或微博。
   * 支持通过 `/店铺列表` 查看所有已记录店铺的绑定状态与在监商品数。
3. **即时按需刷新与手动补录**：
   * 录入新店铺时，系统自动触发初次即时数据抓取，告别漫长等待。
   * 提供 `/刷新店铺 <店铺名>` 随时拉取最新情报并返回诊断信息。
   * 提供 `/录入通知 <店铺名> <补款/开订> <内容>`，当某店通知通过群聊或图文发布时，可一键补录并触发在监用户推送。
4. **自然语言交互与双模操作**：
   * 支持原生 LLM Tool 与对话意图识别：直接对 Bot 说“帮我盯一下猫受屋的初音韶华手办补款”、“GSC近期有什么补款通知”。
   * 同时也提供清晰完整的快捷指令。
5. **每日早报与新开预订雷达**：
   * 支持每日定时推送早报，汇总各大店铺今日最新发布的补款通知与新开预订商品。

## 微信公众号与本地轻量 OCR 图像文字提取

模玩、手办类小店（如淘模玩、猫受屋等）的微信推文经常采用**“少量客套话 + 多张排期海报长图/表格图”**的形式。针对这种情况，插件提供了完全解耦大模型的本地轻量 OCR 支持：

1. **纯本地 CPU 推理，0 Token 成本**：
   - 基于 `RapidOCR (ONNX Runtime)`，完全在本地 CPU 运行，无需消耗任何多模态大模型 Token 额度。
   - **大模型完全解耦**：无论您的 AstrBot 主模型是支持视觉的多模态模型，还是纯文本大模型（如 DeepSeek-R1、Qwen-Coder、Llama-3-Text），本地 OCR 都会提前将长图转为标准文本，确保纯文本模型也能 100% 读懂图片内容。
2. **多层感知与全自动触发**：
   - **微信文章自动提取**：微信推文解析或自动抓取时，若文章内含排期长图，自动对前 N 张海报长图进行并行 OCR，提取手办名称、定金尾款与截止日期并追加至正文中。
   - **群内发链接/发图即时识别**：支持群友直接向 Bot 发送微信公众号文章链接、或发送补款截图海报使用 `/识别补款图片`，Bot 自动识别并入库提醒。

## 微博反爬突破指南 (Cookie 与 RSSHub)

由于新浪微博近期加强了山海防火墙（SHANHAI-SERVER）拦截，无 Cookie 请求可能返回 HTTP 432 或重定向至登录页：
1. **推荐方式 1（一键设置 Cookie）**：
   - 打开电脑浏览器访问 [weibo.com](https://weibo.com) 并登录任意账号；
   - 按 `F12` 打开开发者工具，进入 **Application（应用）** -> **Cookies** -> `https://weibo.com`；
   - 找到名为 `SUB` 的条目并复制其值；
   - 在 QQ 私聊 Bot 发送：`/设置微博cookie SUB=您的SUB值` 即可永久生效！
2. **推荐方式 2（自建 RSSHub）**：
   - 如果您自建了 RSSHub 实例，在 AstrBot Web 控制台的插件配置项中填入 `weibo_rss_base_url`（如 `http://127.0.0.1:1200`），系统将自动走 RSSHub 稳定拉取。

## 补款群“静默嗅探”工作原理

针对未禁言、日常有人闲聊的补款群，插件采用两道过滤与阻断机制：
1. **身份判定**：只检测群主、管理员或指定管理员 QQ 的发言，非管理员发言直接丢弃；
2. **意图特征判定**：只有当发言内容命中“补款/尾款/到货/开补/截单”等通知关键词时才触发解析；
3. **全局阻断 (`stop_event`)**：只要属于补款群内的消息，插件在截获后立即调用 `event.stop_event()` 阻断后续所有事件传播。这意味着 **Bot 在该群内永远不会触发任何闲聊、人格回复或表情互动**，做到真正的“只听不说、零打扰”。
