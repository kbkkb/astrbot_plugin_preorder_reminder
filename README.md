# AstrBot 预售补款提醒与小店情报管家 (`astrbot_plugin_preorder_reminder`)

专为手办、模玩、周边爱好者打造的预售订单与小店补款追踪插件。彻底解决预定太多容易遗忘、淘宝小店不发短信、补款群被闲聊刷屏容易漏看的痛点。

---

## 核心特性

1. **三维立体情报监控**：
   * **QQ 补款群静默嗅探（零打扰）**：监听小店自建的 QQ 预售/补款群。自动过滤群友闲聊，只提取店主/管理员发布的补款与开订通知；**Bot 在群内绝对静默（不发一言、不闲聊、不响应普通指令）**，命中时私聊推送订阅用户。
   * **微博动态监控**：通过移动端公开通道，无需登录轮询各大中型模玩店/官方代理（GSC、猫受屋、B站等）的开订与开补博文。
   * **微信公众号监控**：支持接入 WeWe-RSS / 微信读书源，自动拉取并解析小店发布的《XX月补款清单汇总》推文。
2. **小店档案库与渠道绑定**：
   * 支持自然语言或指令创建店铺档案，为每个小店绑定其补款群、公众号或微博。
   * 支持通过 `/店铺列表` 查看所有已记录店铺的绑定状态与在监商品数。
3. **自然语言交互与双模操作**：
   * 支持原生 LLM Tool 与对话意图识别：直接对 Bot 说“帮我盯一下猫受屋的初音韶华手办补款”。
   * 同时也提供清晰完整的快捷指令（`/店铺列表`、`/订阅补款`、`/我的补款`、`/今日补款` 等）。
4. **每日早报与新开预订雷达**：
   * 支持每日定时推送早报，汇总各大店铺今日最新发布的补款通知与新开预订商品。

## 自然语言交互示例

您可以直接 @机器人 进行自然对话：
* **添加店铺**：`@Bot 录入店铺【猫受屋】，补款群号是 720694396，微博是 12345678`
* **订阅商品**：`@Bot 帮我盯着【猫受屋】的【初音韶华手办】补款，定金付了50块`
* **查看清单**：`@Bot 查一下我订了哪些手办还没补款`
* **查看店铺**：`@Bot 看看我们记录了哪些店铺`
* **完成补款**：`@Bot 我已经补完初音韶华了`
* **查询今日**：`@Bot 今天有什么补款？`、`@Bot 今天有哪些新开预定？`

## 补款群“静默嗅探”工作原理

针对未禁言、日常有人闲聊的补款群，插件采用两道过滤与阻断机制：
1. **身份判定**：只检测群主、管理员或指定管理员 QQ 的发言，非管理员发言直接丢弃；
2. **意图特征判定**：只有当发言内容命中“补款/尾款/到货/开补/截单”等通知关键词时才触发解析；
3. **全局阻断 (`stop_event`)**：只要属于补款群内的消息，插件在截获后立即调用 `event.stop_event()` 阻断后续所有事件传播。这意味着 **Bot 在该群内永远不会触发任何闲聊、人格回复或表情互动**，做到真正的“只听不说、零打扰”。
